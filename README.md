# SG_CDEZ

SG CDEZ Is Sistema de Gestión para Casa Diurna Esperanza del Zurquí, a non-profit organization that advocates for the care of the elderly.
The application is designed to assist in the digitalization of all major interdisciplinary processes such as elderly and professional management, as well as aiding the process of medical and/or professional consults (including nursing, physical therapy,  psychology, etc.).
